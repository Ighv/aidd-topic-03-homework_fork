# Отчёт о работе (ветка cline)

## Какие задачи ставились

Задания 1–4 из `HOMEWORK.md`: анализ кода, восстановление требований, модернизация
и исправление дефектов, новая функциональность. Для задания 4 выбран вариант
«Персональный мониторинг акций».

## Основной промпт

Работать в отдельной копии проекта, не копировать решения из ветки `opencode`,
выполнять задания по порядку 1 → 2 → 3 → 4, результат закоммитить в ветку `cline`.
Для новой функции — список наблюдения, целевые цены и уведомления без дублей.

## Что получилось

- `ANALYSIS.md` — анализ и восстановленные требования, включая сценарии пользователя.
- `MODERNIZATION.md` — что было устаревшим, какие дефекты исправлены.
- `NEW_FEATURE.md` — требования и проверка новой функции.
- Код: `Watchlist`, `PriceAlert`, миграция `0008`, веб-страницы, REST API,
  Celery-задача `check_alerts`.

## Ошибки и проблемы

- Старые зависимости (Django 4.1, Celery 5.2) плохо работают на Python 3.14.
- PostgreSQL в настройках не был запущен — пришлось перейти на SQLite.
- В первой версии новой функции повторное добавление в watchlist давало 500,
  а `@login_required` отправлял на несуществующий `/accounts/login/`.
- В `ANALYSIS.md` сначала не было сценариев пользователя, а по заданиям 3–4 не было документов.

## Корректировки

- Добавлены сценарии, `MODERNIZATION.md` и `NEW_FEATURE.md`.
- Дубль watchlist закрыт через `get_or_create` и валидацию в API.
- Добавлен `LOGIN_URL`, исправлен URL пользователя на `/user/login/`.
- Проверка уведомлений вынесена в сервис, чтобы её можно было тестировать без Celery.

## Как проверялось

- `python manage.py check` — ошибок нет.
- `python manage.py migrate` — миграции применяются.
- `python manage.py test` — 19 тестов, все проходят.
- Проверены страницы watchlist/alerts, API, дубли, срабатывание уведомления и изоляция пользователей.
