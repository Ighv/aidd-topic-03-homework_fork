# Отчёт (`opencode`, первый)

## 1. Какие задачи ставились агенту

1. Анализ исходного кода: назначение, стек, структура, архитектура, зависимости, модель данных, обработка запросов и работа с БД.
2. Восстановление фактически реализованных требований: нумерованный список с подтверждением в коде, бизнес-правила, отдельно дефекты и неоднозначности.
3. Модернизация, устранение дефектов, рефакторинг с обязательным успешным запуском без потери функциональности.
4. Новая функция, вариант «Персональный мониторинг акций»: список наблюдения, целевые уровни, уведомления без дублей.

Дополнительно: разделить исправление ошибок и новую функциональность, результаты проверять

## 2. Промпты

Постановка для первого прохода — текст `HOMEWORK.md` плюс уточнения: вариант новой функции №1, дефекты отдельно от требований, результат закоммитить и запушить в ветку `opencode`.


## 3. Ошибки и проблемы при работе



Нет node/npm в PATH: `node: command not found`, распаковка `node-v20.18.1-linux-x64` в `/tmp` без root.

Несовместимость окружения: Python 3.14 с Django 4.1.13 и Celery 5.2.7, использован подготовленный `.venv`.

Сломанный pip в новом venv: `No module named 'pip._internal.utils'`, `WARNING: Ignoring invalid distribution ~ip`, Django распаковался без `django/utils`; `get-pip.py` не помог.

Нет PostgreSQL: приложение не стартовало, `DATABASES` переключён на SQLite в обеих ветках.

Ошибка генерации шаблонов: `bash: unexpected EOF while looking for matching '"'` в heredoc, файлы созданы отдельными командами.


## 4. Какие корректировки вносились

Замена PostgreSQL на SQLite для локального запуска и тестов.

Дефекты выписывались отдельным списком, чтобы не попадали в FR.

Переписаны `market_data.get_last_data`, `services/graph.get_graph`, `tasks.update_last_price`: исходный код падал на `None` и игнорировал `nano` у цены.

## 5. Как проверялись результаты

`python manage.py check` → `System check identified no issues (0 silenced).`

`python manage.py migrate` → применяются миграции `dashboard.0001`–`0008`.

`python manage.py test` → `Ran 10 tests ... OK` в обеих ветках.

## 6. Время и итерации

Проход 1 — около 4 циклов: анализ, правки окружения, модернизация, новая функция, коммит

Основное время opencode ушло на совместимость зависимостей, а не на код.

## 7. Выводы

Агент устойчиво ведёт длинные многошаговые задачи без потери исходной функциональности. Слабое место — окружение: старые зависимости и отсутствие инструментов в PATH требуют ручных обходов, которые агент делает сам, но с заметным числом итераций. Проверка обязательна: игнорирование `nano`, падение на `None` и коммит не в ту ветку найдены сверкой результата.
